# 🔐 PassGuard — Password Strength Analyzer & Security Suggestions

> A defensive security tool that analyzes password strength locally in the browser and provides practical security guidance.

🌐 **Live Demo:** https://passwordstrengthanalyzersecuritysuggestion.lovable.app

## 📌 Overview

**PassGuard** is a browser-based password security analyzer designed to help users understand whether a password is weak because of length, predictability, common patterns, or personal-context clues.

The project is intentionally privacy-focused: the live application states that analysis runs **100% locally**, passwords are **never stored**, and local history keeps only score/class/length metadata. citeturn177074view0

## ✨ Key Features

- 🔎 Real-time password strength analysis
- 📊 Strength score from **0–100**
- 📏 Password length analysis
- 🧮 Raw entropy and adjusted entropy estimates
- 🧩 Character-pool analysis: lowercase, uppercase, digits, symbols, spaces
- 🧠 Pattern-based weakness detection
- 🗂️ Leaked/common-password awareness
- ⏱️ Estimated offline crack time
- 🛡️ Security suggestions such as password uniqueness and MFA
- 👤 Optional personal-context checks
- 🎲 Passphrase generation using random words
- 💾 Local history using metadata only
- 🔒 No password storage in local history

The application itself notes that its crack-time model assumes an offline attacker at **10¹⁰ guesses/second** and that no formula can perfectly measure password strength. Treat the score as guidance, not a guarantee. citeturn177074view0

## 🔐 Security & Privacy

PassGuard is intended as a **defensive cybersecurity learning project**.

Important principles:

- Do not enter passwords that are currently used for important accounts into public demos.
- Never commit passwords, API keys, tokens, `.env` files, or other secrets to GitHub.
- Frontend validation should not be treated as a security boundary.
- Password strength scores are estimates, not cryptographic guarantees.
- Prefer unique passwords and password managers.
- Enable multi-factor authentication wherever available.

## ⚙️ How the Scoring Model Is Presented

The application describes its model as:

```text
Raw Entropy = Password Length × log₂(Character Pool Size)
```

Detected patterns are then used to reduce the adjusted estimate, and leaked-password detection can heavily cap the resulting estimate. The app also converts the estimate into an offline crack-time approximation. citeturn177074view0

This is a heuristic educational model, not a guarantee of real-world cracking resistance.

## 🎯 Portfolio Highlights

### Problem

Many password checkers focus on simple composition rules such as “include a symbol and a number.” That can miss predictable patterns.

### Approach

PassGuard combines:

```text
Length
   ↓
Character Pool
   ↓
Entropy Estimate
   ↓
Pattern Detection
   ↓
Adjusted Estimate
   ↓
Strength Score + Security Guidance
```

### Outcome

Users receive an understandable security assessment without needing to send the password to a remote service.
